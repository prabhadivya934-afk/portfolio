## Run locally

Open `index.html` in a modern browser. No build step, package installation, or backend is required. For local development, VS Code's Live Server extension is also suitable.

## Publish or update

Upload the complete folder to your GitHub repository or drag it into a static hosting service such as Netlify. Keep the `assets` folder next to `index.html` so the résumé download works.
